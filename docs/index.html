Personal finance for India that never leaves your phone

SMS and statement driven tracking of spends, cards and rewards, bills, loans, insurance, salary, provident fund and wealth. Everything is stored on the device. There is no account, no server and nothing is uploaded.

Run it

Node 18 or newer.

npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
npm run preview    # serve the production build

Android app (reads SMS on the phone):

npm run build
npx cap sync android
npx cap open android

Rebuild these docs and the screenshots (uses made-up data, needs Chrome or Edge):

npm i --no-save puppeteer-core
npm run dev                                  # in another terminal
node docs/tools/capture.mjs http://localhost:5173
node docs/tools/build-docs.mjs
node docs/tools/make-pdf.mjs                 # writes docs/FinPing-Demo.pdf
